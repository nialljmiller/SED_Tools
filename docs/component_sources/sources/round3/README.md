# Round 3 research and ingestion

The reports and machine-readable inventories here are the workers' 2026-10-23 research packet. Source bytes are held on Vega at `/home/nill/agent-share/projects/sed-tools-components/round3/`; hashes and original URLs are in `codex/manifest.json`, `ground-agent/inventory.json`, and `space/inventory.json`. Research files are evidence, not automatically published bands.

The application currently ingests four explicitly checked sets through the shared tabular builder: CAHA/PANIC (7 in-band filters), WHT/INGRID (20 warm/cold filter variants), IRTF/NSFCam (26 filter-only scans), and Liverpool/IOO (7 filter curves, CCD QE and cryostat-window transmission). These comprise 60 published variants; PANIC's seven root passbands were already mirrored from SVO, so the public index grew by 53 filters. Their raw bytes are kept outside Git; on Cirrus they are archived at `/media/data3/MESA/SED_Tools/data/source_evidence/round3/`. For an offline rebuild, point `--raw` at the parent directory containing `round3/`.

**Correction to the harvested inventory:** the seven NSFCam Mauna Kea replacement files (`*mk_trans.dat`) label their ordinate `Transmission (%)`, while the earlier NSFCam files use fractions. The inventory currently marks all 39 files as fractions. The builder reads each header class with its proper scale; future research exports should correct the inventory before using it as a general parser specification.

Unserved files remain available for further review. In particular, PANIC's out-of-band files are optical density, JCMT model columns lack a reliable mapping, MMT radial/multicolumn tables need a dedicated parser, and the space missions include combined responses, frequency-domain responses and effective areas that cannot all be treated as ordinary wavelength/filter throughput. NSFCam's PK50 combinations need band-specific blocker representation, Liverpool's separate H-alpha scans need an epoch relationship to the QE/window model, and the other ground packets include historical or uncertain versions. See the four worker reports and independent review before adding any of these to the public mirror.

The Cirrus `server` branch was merged from `main` and its index regenerated after building. The public index reported 3,963 filters in 75 facilities. All 28 registered source sets had every file declared by their manifest and every root passband listed in the MESA index; this is file completeness, not a claim of complete optics/QE for each band. Only LSST, Liverpool IOO, VISTA and HSC expose filter+optics+QE for every primary band. The other supported sets expose whatever original factors have been validated, including partial per-band coverage for HST/JWST and filter-only coverage for the new PANIC, INGRID and NSFCam sets.
