## Material ingestion limitations

1. MMT `filterthroughput.megacamu` has 12 named tab-separated columns, while numeric whitespace splitting yields 10 tokens where blank cells occur. Preserve tab separators and empty cells before assigning physical column names. Large values in FLUX/NU-related columns are not transmission failures.
2. MMT `z__filter_MMT.txt` contains a numeric spreadsheet preamble, auxiliary columns, and variable numeric-row widths. Its inventory `numeric_rows` is correctly a **numeric-line count**, not a validated spectral sample count. A format-aware extraction must select wavelength plus the five radial-response columns and exclude numeric preamble/auxiliary data.
3. JCMT model files have no headers identifying each of their 14/15 response columns. Do not claim every individual component is identified from column order alone. The landing page documents the combined model and its exclusions, but a column dictionary is still needed. Model frequency coordinates around 270–410 are consistent with GHz, an inference here, not an explicit file unit.
4. PANIC out-of-band OD needs `T = 10**(-OD)` if a transmission product is desired; preserve original OD as a separate component representation. Do not treat OD values up to ten as a transmission percentage.
5. Percent transmission, fraction transmission, arbitrary measured profiles, optical density and detector/beam-splitter response are distinct. The raw inventory intentionally lacks interpreted role/unit fields; the final report should preserve these distinctions before runtime ingestion.
