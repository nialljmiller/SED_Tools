FILTER PROFILES BY FACILITY
Published path shows which optical-path elements are already included in each downloadable filter curve. Separate component curves shows independently downloadable files by element and the number of bands covered. These are distinct: a published curve can include optics or detector response even when no separate file is available. Detector type describes photon or energy counting, not an additional optical component. DETAILS opens each instrument's band properties (pivot, width, zero points), descriptions, references to cite, and where every curve came from, including what the SVO Filter Profile Service said about it. Link to an instrument with #Facility/Instrument.

📖 HOW TO USE
For MESA Users:
  1. Download desired model folder (includes flux_cube.bin + lookup_table.csv)
  2. Copy to $MESA_DIR/colors/data/stellar_models/
  3. Set in your inlist: stellar_atm = 'ModelName/'
For Filter Profiles:
  1. Download Facility/Instrument folder
  2. Copy to $MESA_DIR/colors/data/filters/
  3. Set in your inlist: instrument = 'Facility/Instrument'
