FILTER PROFILES BY FACILITY
Published path shows which optical-path elements are already included in each downloadable filter curve. Separate component curves shows independently downloadable files by element and the number of bands covered. These are distinct: a published curve can include optics or detector response even when no separate file is available. Detector type describes photon or energy counting, not an additional optical component. DETAILS opens each instrument's band properties (pivot, width, zero points), descriptions, references to cite, and where every curve came from, including what the SVO Filter Profile Service said about it. Its SYNTHETIC PHOTOMETRY section shows each band's bolometric correction or magnitude in the stellar grids. Link to an instrument with #Facility/Instrument. Downloading several filters: tick whole instruments here, or single bands inside DETAILS, then press DOWNLOAD ZIP. Each instrument comes as a MESA-ready folder (the curves, an index file listing them, properties and info), with a CITATION.txt of the papers, acknowledgements and terms to honour.

📖 HOW TO USE
For MESA Users:
  1. Download desired model folder (includes flux_cube.bin + lookup_table.csv)
  2. Copy to $MESA_DIR/colors/data/stellar_models/
  3. Set in your inlist: stellar_atm = 'ModelName/'
For Filter Profiles:
  1. Download Facility/Instrument folder
  2. Copy to $MESA_DIR/colors/data/filters/
  3. Set in your inlist: instrument = 'Facility/Instrument'
© CREDITS & CONTACT

Every filter curve here comes from the team that published it. Each instrument's DETAILS panel lists where its curves came from, the papers to cite, the acknowledgement the data provider asks for, and the terms under which the curves are shared; please cite the original work as well as this archive. Curves taken from the SVO Filter Profile Service are credited to it. Vega quantities use CALSPEC's model of Vega (vega/), and true colours use the CIE's published colour-matching functions. The Sun's band-averaged flux (SUN Fλ) uses CALSPEC's solar spectrum (sun/): sun_reference_stis_002 below 9600 Å (Colina, Bohlin & Castelli 1996) and the Kurucz model sun_mod_001 above, from CALSPEC (Bohlin, Gordon & Tremblay 2014). The extinction ratio A/AV at each band's pivot wavelength uses the Fitzpatrick (1999) law with RV = 3.1, as implemented in dust_extinction (Gordon 2024); it is left blank outside the law's range (0.1 to 3.3 µm).
